# O Gaúcho Churrascaria

Site institucional e cardápio digital da Churrascaria O Gaúcho, em São Luís — MA.

## Funcionalidades

- Cardápio organizado por categorias
- Carrinho local com controle de quantidades
- Envio do pedido para confirmação pelo WhatsApp
- Tema claro e escuro
- Layout responsivo para celular e computador

## Tecnologias

HTML, CSS e JavaScript.
